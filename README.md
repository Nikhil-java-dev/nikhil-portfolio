## 🚀 Run Locally

Clone the project

```bash
git clone https://github.com/Nikhil-java-dev/nikhil-portfolio.git
```

Go to the project directory

```bash
cd nikhil-portfolio
```

Install dependencies

```bash
npm install
```

Start the server

```bash
npm run dev
```
